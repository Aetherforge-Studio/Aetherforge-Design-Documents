## Length

_Leave room: translations from English often run longer, up to a third in some languages. Set max_length from the space on screen, not from the English._

## Plurals and numbers

_Languages count differently: Polish has three plural forms where English has two. Put the number after a label (Salt: {count}) or use your engine’s plural system, and format numbers and dates for each language._
